Visual review and interpretation
-------------------------------
The fixed moderate-blur example 000061 is also used in the prior ID-card PDF.
Contrast stretching makes letters darker but also strengthens card background
patterns; vertical smearing remains. Mild unsharp masking changes appearance
only slightly. Edge masks follow the existing blurred strokes and cannot identify
missing original character boundaries. The best settings had no RGB clipping,
so their higher OCR errors cannot be attributed solely to clipped pixels. The
strongest S-curve tested (strength 6) clipped 1.17% of pixels on average.

Best edge-guided settings: amount 0.5, sharpening sigma 1, detection sigma 1,
gradient threshold 3. Versus Wiener: 10 images improved, 13 worsened, 7 tied.
No tested extra stage improved pooled OCR accuracy. Keep the optional stages off
for this sequence; retain them for evaluation on other independent cards.

Validation of implementation: 35 tests passed. Frozen-config application without
reference text reproduced all 30 selected outputs and generated block OCR.
