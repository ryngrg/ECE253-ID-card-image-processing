Interpretation and verification
New automatic bank: 2814 / 4632 character errors (60.75%), versus original 2913 (62.89%) and previous automatic bank 2863 (61.81%).
Gain: 99 fewer errors versus original (2.14 percentage points); 49 fewer versus previous bank (1.06 points).
Retrained shared filter: 2813 errors (60.73%), only one error fewer than the new bank. No clear strength-selection benefit.
Medium and strong independently selected identical settings; the bank contains two distinct filters, not three artificially forced settings.
Mild worsens versus unfiltered input. Medium worsens versus the previous bank. Strong improves but remains at 79.75% CER.
Old single-card ~70% strong CER is not directly comparable: new cards, field set, and provisional sharpness groups differ.
The validation-selected configuration remains frozen; no tuning or pipeline replacement was done using test results.
48 tests passed. All 60 geometry-only application images matched evaluated pixels at native dimensions.
Persistent C API vs existing CLI parity: 53 original + 45 filtered training fields, plus 106 held-out fields; no normalized text differences.
Visual review: predetermined mild/medium/strong test examples show retained blur and occasional OCR regressions. Strong field-geometry spot-check confirms correctly located but heavily smeared text.
